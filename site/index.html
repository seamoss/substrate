git-backed context layer

Shared context for humans & AI agents.

Agents forget between sessions. Teams lose decisions across repos. Substrate keeps durable project context — constraints, decisions, conventions — in committed .substrate/ files, synced through the git you already use. No server. No accounts.

Agents keep context

          

            Rehydrate any session with substrate brief --format agent — prioritized,
            token-budgeted, constraints first.
          

        

        

          
Teams share truth

          

            Context is versioned next to the code and travels through pull requests like everything
            else. Clone the repo, get the context.
          

        

        

          
No infrastructure

          

            Git is the transport. Identity and access control are your git host's. Nothing to run,
            nothing to log into.

Quick start

        
# Initialize — no account needed
substrate init myproject

# Capture context as you work
substrate add "All API responses must be JSON" --type constraint
substrate add "Using PostgreSQL for ACID" --type decision
substrate add "My local DB is on port 5544" --type note --private

# Share it: write files, then commit with git
substrate sync push
git add .substrate && git commit -m "Add context" && git push

# On another machine
git pull && substrate sync pull
